1. System architecture

Every path from the screen to the database goes through one gate. Nothing the agent does can move money.

2. The Ask loop (what happens when you type a question)

LangGraph state machine. Dashed boxes use the model router when a key is configured; otherwise rules run instead. Same numbers either way.

3. What each user action invokes

Reads are plain queries. Writes always pass through the executor (policy, validation, audit). User-only actions are denied to the agent.
